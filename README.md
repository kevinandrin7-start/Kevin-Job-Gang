# Kevin's Job Gang

Animated dashboard of the job hunt agents (Captain, Scout, Tailor, Turtle, Scribe) passing data to each other through the Ledger, served with GitHub Pages.

- `index.html`: the dashboard (no build step).
- `data.enc.json`: encrypted snapshot of the Ledger (AES-GCM). The page asks for Kevin's email and password and decrypts it in the browser.

## Updating the data

`data.json` is generated by `job-hunt/dashboard/build_data.py` (in the project files) from the private Ledger plus `agent_state.json`, keeping only public posting info. Run `python3 build_data.py <repo>/data.json` (it writes `data.enc.json` when the dashboard password is set in the private config), commit and push; the page re-fetches it every minute.

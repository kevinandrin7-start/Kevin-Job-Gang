# Kevin's Job Gang

Animated dashboard of the job hunt agents (Captain, Scout, Tailor, Turtle, Scribe) passing data to each other through the Ledger, served with GitHub Pages.

- `index.html`: the dashboard (no build step).
- `data.json`: public-safe snapshot of the Ledger (company, title, score, source, status only). Replace it to update the page.

## Updating the data

`data.json` is generated by `job-hunt/dashboard/build_data.py` (in the project files) from the private Ledger plus `agent_state.json`, keeping only public posting info. Run `python3 build_data.py <repo>/data.json`, commit and push; the page re-fetches it every minute.
